# Playbook 17.11.1 preparation

Prepared on 2026-10-21; not tagged or released.

This patch release carries the classified-entry lifecycle fix from
`f31250de548d78f2576f753e5f564e1988604b6f` ([IR-116](../../specs/intents/116-classified-entry-lifecycle.md)).
It preserves required classification fields and exact Boss text on terminal
restart, and clears earlier run exchanges only for a valid new entry.
Refused entries, replies and global interrupts retain the current run.
Dependencies and the locked Cligent 0.36.0 binding are unchanged.

The fix candidate passed the canonical model-free integration checks: build,
spec lint, 2,842 main tests with 24 skips, the separate 146 capability tests,
link checks and SPDX checks. The shared-runtime segment includes 261 tests.
Those results precede this version/changelog/record-only preparation; they do
not establish packed or real-agent acceptance for 17.11.1.
The historical failed broad run remains qualified in IR-116.

Before tagging, the remaining release gates are the full canonical
`pnpm smoke:release` followed by `pnpm test:acceptance`, compiled-sibling and CI
verification, and review/commit/push to main under
[release-10](../../specs/packages/release.md#release-10).
Neither smoke nor real-agent acceptance has run for this release preparation.
The real-agent gate must request `gpt-6.1-sol` and `claude-opus-5-5` through
`PLAYBOOK_ACCEPTANCE_CODEX_MODEL` and `PLAYBOOK_ACCEPTANCE_CLAUDE_MODEL`.
Requested model names alone do not independently identify the serving backend.

This change does not alter interactive presentation/layout or the declared or
locked Cligent version, so it does not itself trigger the conditional manual
presentation check in [release-26](../../specs/packages/release.md#release-26).
Reassess that condition if the release inputs change.
Raw live logs and retained scratch evidence remain private outside the repository.
No publication, installation or adoption is claimed by this record.
