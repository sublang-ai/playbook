# Playbook 19.0.0 preparation

## Scope and version classification

The reviewed GEARS range is `v18.3.1..31f9fbd` (DR-108).
This is a MAJOR release because the published `slc/*` definitions change the compiled GEARS form that downstream compilers consume.
The eight reference packages now distinguish actions, requirements and verification items. Consumers that previously mapped every item to a machine state must update their checker.
The release also includes `31f9fbd..792ea9b`, which adds script-output telemetry (DR-106) and records the executed command and its settlement facts (DR-107).
The release preparation changes no reference machine.
