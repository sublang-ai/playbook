# Playbook 19.0.1 preparation

## Scope and version classification

The release range is `v19.0.0..e54dc69`, which holds only pull request #114 (DR-109).
This is a PATCH release: a chunked session's manifest write no longer reads and verifies the whole replay chain twice.
The public interface, the physical storage format, the `slc/*` definitions, the reference GEARS packages and the reference machines are unchanged.
The release preparation changes only the version, the changelog and this record.

- [x] On `e54dc69` with the 19.0.1 version and changelog applied, `pnpm install --frozen-lockfile` and `pnpm build` produced zero generated-file drift.
