# IR-049: Shared session store and replay stream

## Status

Incomplete

## Intent

Implement [DR-042](../decisions/042-shared-session-store-and-replay-stream.md) so the interactive launcher, headless runner, and an external host share one directory for canonical Playbook manifests, host sidecars, and token-free replay streams without changing the settled lifecycle capabilities or frozen stream ABI.
The behavior and verification contracts already live in [[playbook-cli-4](../packages/playbook-cli.md#playbook-cli-4)], [[playbook-cli-23](../packages/playbook-cli.md#playbook-cli-23)], [[playbook-cli-46](../packages/playbook-cli.md#playbook-cli-46)], [[playbook-cli-73](../packages/playbook-cli.md#playbook-cli-73)] through [[playbook-cli-84](../packages/playbook-cli.md#playbook-cli-84)], [[release-18](../packages/release.md#release-18)], [[release-28](../packages/release.md#release-28)], and [[release-33](../packages/release.md#release-33)].
The first task closes the semver-stable facade's exact JavaScript identifiers, signatures, declaration exports, token-free session summary, capability-scoped stream result and live-status shapes, and package-owned opaque replay-payload types under [[meta-34](../meta.md#meta-34)]; the remaining tasks implement and verify that fixed surface without widening it.
Cross-repository review established that the dependent host's content writer matches the semantic JSONL ABI, while its current privacy modes and reader require adoption in that repository rather than a compatibility relaxation here.

## Deliverables

- [x] The package specs name the exact narrow facade, token-free session-summary boundary, and opaque replay-payload boundary without adding a capability beyond [DR-042](../decisions/042-shared-session-store-and-replay-stream.md).
- [x] The internal store reads and writes the frozen version-1 replay stream, strips provider resume credentials, and keeps only a clean contiguous readable prefix.
- [x] Replay appends require the session lease, resume after the complete retained prefix, checkpoint at settlement and release, and latch and stop without failing an agent turn.
- [x] The published JavaScript and declaration facade exposes only the decided module, token-free session summary, store, and narrow lease surfaces over the same private implementation and validators that the front ends use through their richer internal leases.
- [x] Both front ends tee every observed host record in order, add roles where the trace makes them known, preserve successful presentation and turn outcomes, and attempt only their bounded native-channel warning when replay becomes incomplete.
- [x] The optional top-level `sessions` locator resolves before selection in both front ends and never enters a persisted projection.
- [x] A checked-in cross-repository fixture, focused integration coverage, documentation, and changelog describe and verify the implemented shared-store and replay behavior.
- [ ] The packed-consumer smoke and affected release gates verify the complete cutover without a version bump or release tag.
