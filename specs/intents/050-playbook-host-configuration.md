# IR-050: Playbook host configuration

## Status

Incomplete

## Intent

Evolve the shared Playbook host configuration in three independently reviewable slices: adapter-scoped fast-mode tuning, coordinated automatic relocation of the irreplaceable user-authored config, and a proven starter agent lineup.
Keep authored SDLC workflow sources and their compiled artifacts outside this intent.

## Deliverables

- [ ] Fast mode is a Spex-coordinated, Cligent-validated optional-boolean tuning dimension whose absent, explicit-false, and explicit-true states survive complete calls and durable execution, remain nonstructural, refresh on ordinary reopen, and persist exactly on uncertain retry.
- [ ] Playbook and Spex resolve one user config below `SPEX_HOME`, with coordinated namespace ownership, target-preserving absolute locator rewrites, retirement of the legacy regular file behind a permanent compatibility alias, interrupted-publication recovery, profiles-content migration, and fallback seeding specified and verified before relocation is enabled.
- [ ] The bundled Playbook starter, Spex's seed of the shared file, and public configuration documentation carry the requested Captain, Coder, and Reviewer lineup without changing notifications, enabled playbooks, or role bindings.
- [ ] Decision records, package behavior, integration verification, dependency metadata, and the full configured gate agree with the implementation without modifying excluded SDLC sources or compiled artifacts.
